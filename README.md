# GamePick — مُرشِّح ألعاب عربي

موقع يسأل المستخدم ٦ أسئلة قصيرة عن تفضيلاته، ثم يقترح ٥ ألعاب حقيقية **مع سبب مكتوب بالعربي** لكل لعبة يشرح لماذا تناسبه هو تحديداً. بدون تسجيل دخول.

## المعمارية

```
واجهة React (Vercel)
   │  POST /functions/v1/recommend
   ▼
Supabase Edge Function «recommend»
   │  يخفي رابط n8n · يتحقق من المدخلات · يحدّ من المعدل · يكتب في قاعدة البيانات
   │  POST + x-app-secret
   ▼
n8n Workflow
   Webhook → Build Query → RAWG API → Trim → AI Agent (Gemini) → Merge → Respond
   ▼
Supabase (PostgreSQL + RLS)
   sessions · recommendations · feedback
```

## قراران يحكمان التصميم

**١. الذكاء الاصطناعي يرتّب ولا يبحث.** RAWG يجلب ٢٠ لعبة حقيقية بناءً على المنصة والنوع والفترة الزمنية، والوكيل يختار منها ٥ ويكتب سبب الترشيح. كل بيانات العرض (الاسم، الصورة، الرابط) تُؤخذ من RAWG بعد ربطها بالمعرّف — فيستحيل ظهور لعبة مختلقة.

**٢. الفلاتر الأساسية فقط تُرسل لـ RAWG.** المزاج وأسلوب اللعب والوقت المتاح لا تُرسل كفلاتر، لأن دمجها كلها بـ AND يعطي صفر نتائج في معظم الحالات. هذه الثلاثة تصبح مهمة الذكاء الاصطناعي: يقارنها بوسوم كل لعبة ويرتّب على أساسها.

**٣. مسار احتياطي إجباري.** إذا فشل الوكيل أو أعاد JSON غير صالح، تتولى عقدة `Merge` ترتيباً حسابياً بالقواعد وترجع النتائج على أي حال. الموقع لا ينهار أمام أي زائر.

## التشغيل محلياً

```bash
npm install
```

انسخ `.env.example` باسم `.env` وعبّئه:

```
VITE_SUPABASE_URL=https://xxxxxxxx.supabase.co
VITE_SUPABASE_ANON_KEY=sb_publishable_xxxxxxxx
```

ثم:

```bash
npm run dev
```

## قاعدة البيانات

ثلاثة جداول مع تفعيل RLS على الجميع:

| الجدول | صلاحية الزائر (anon) |
|---|---|
| `sessions` | **لا شيء** — إجابات المستخدمين محجوبة تماماً عن الواجهة |
| `recommendations` | قراءة فقط — لتعمل صفحة المشاركة `/r/:id` |
| `feedback` | إضافة فقط |

الكتابة في `sessions` و`recommendations` تتم حصراً من الـ Edge Function بمفتاح السر (يتجاوز RLS).

## أسرار الـ Edge Function

| الاسم | الغرض |
|---|---|
| `N8N_WEBHOOK_URL` | رابط الـ webhook |
| `N8N_SHARED_SECRET` | يمنع استدعاء n8n مباشرة وتخطي تحديد المعدل |
| `SB_SECRET_KEY` | الكتابة في قاعدة البيانات |

مفاتيح RAWG و Gemini تُحفظ داخل n8n فقط ولا تصل الواجهة أبداً.

## الحمايات

- تحديد المعدل: ١٠ طلبات لكل عنوان IP كل ١٠ دقائق (عنوان الـ IP يُخزَّن مُجزّأً، لا نصاً صريحاً).
- التحقق من كل قيمة مُدخلة مقابل قائمة مغلقة قبل الوصول لأي خدمة خارجية.
- قفل الـ webhook بمفتاح مشترك.
- مهلة ٤٥ ثانية على الاتصال بـ n8n.
